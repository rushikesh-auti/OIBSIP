# OIBSIP - Task 2: Tribute Page

This is the second task of the **OIBSIP Internship**, where a responsive **Tribute Page** is created using **HTML** and **CSS**.

## Project Overview

The Tribute Page is designed to honor and appreciate an inspiring personality through an attractive and responsive webpage.

The webpage includes:
- Biography section
- Images
- Styled layout
- Responsive design

The project focuses on improving frontend development and UI designing skills.

## Project Structure

```

task2-tribute-page/
│
├── index.html
├── style.css
├── images/
├── README.md

```

## Features

- **Responsive Design**: Works smoothly on mobile, tablet, and desktop devices.
- **Modern UI Layout**: Clean and attractive webpage structure.
- **Image Integration**: Includes images with proper alignment and styling.
- **Typography & Styling**: Improved readability with modern fonts and spacing.

## Installation

1. Clone the repository:

```
git clone https://github.com/rushikesh-auti/OIBSIP.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
