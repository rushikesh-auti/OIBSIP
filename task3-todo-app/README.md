# OIBSIP - Task 3: To-Do Web App

This is the third task of the **OIBSIP Internship**, where a responsive **To-Do Web Application** is developed using **HTML**, **CSS**, and **JavaScript**.

## Project Overview

The To-Do Web App helps users manage their daily tasks efficiently.

The application allows users to:
- Add new tasks
- Mark tasks as completed
- Delete tasks
- View pending and completed tasks separately

The project also uses **LocalStorage** to save tasks even after refreshing the browser.

## Project Structure

```

task3-todo-app/
│
├── index.html

```

## Features

- **Responsive Design**: Works smoothly on mobile, tablet, and desktop devices.
- **Task Management**: Add, complete, and delete tasks easily.
- **Pending & Completed Sections**: Separate sections for better organization.
- **LocalStorage Support**: Saves tasks in browser storage.
- **Interactive UI**: Clean and user-friendly interface.
