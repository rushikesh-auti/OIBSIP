# OIBSIP - Task 4: Login Authentication System

This is the fourth task of the **OIBSIP Internship**, where a simple **Login Authentication System** is developed using **HTML**, **CSS**, and **JavaScript**.

## Project Overview

The Login Authentication System allows users to:
- Register with a username and password
- Login using registered credentials
- Access a secured dashboard page
- Logout securely

The project uses **LocalStorage** to store and manage user authentication data.

## Project Structure

```

task4-auth-system/
│
├── index.html
├── dashboard.html
├── style.css
├── script.js
├── README.md

```

## Features

- **User Registration**: Allows users to create an account.
- **User Login**: Authenticates users using stored credentials.
- **Secured Dashboard**: Restricts dashboard access without login.
- **Logout Functionality**: Allows users to securely logout.
- **Show/Hide Password**: Improves user experience.
- **Responsive Design**: Works smoothly across devices.
